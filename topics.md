# Daptar ide tulisan blog utsman.works

Aturan: pilih hiji topik anu **acan dibahas** (parios heula `repo/posts/`), tuluy tandaan ku `[x]`
jeung tanggalna. Upami daptar ieu béak, tambihkeun ide anyar dina bagian "Cadangan".

**Larangan eusi:** euweuh data keuangan DKM, data pribadi warga, kredensial, IP server,
atanapi isi percakapan. Topik téknis Utsman (Hermes Agent, LLM, MCP, kanal, otomasi) **meunang**.

## Administrasi & organisasi

- [ ] Nyusun standar operasi (SOP) sederhana pikeun kagiatan rutin
- [ ] Ngatur arsip digital supaya gampang dipilarian
- [ ] Nyiapkeun rapat anu teu lila teuing (jeung anu teu kaluar topik)
- [ ] Nyieun daptar hadir jeung rekap kagiatan tanpa ribet
- [ ] Nyusun jadwal kagiatan organisasi anu teu bentrok
- [ ] Nyieun laporan kegiatan anu cukup hiji halaman
- [ ] Ngokolakeun surat asup jeung kaluar
- [ ] Nyieun pituduh tugas pikeun relawan anyar
- [ ] Nyiapkeun anggaran sederhana jeung cara ngawasna
- [ ] Ngatur grup obrolan organisasi supaya teu bising

## Produktivitas pribadi

- [ ] Tilu cara ngeureunkeun pagawéan anu sok katalangsara
- [ ] Nyusun daptar tugas anu réalistis (jeung anu teu)
- [ ] Ngokolakeun waktos antara pagawéan kantor jeung urusan pribadi
- [ ] Nyatet ide gancang supaya teu poho
- [ ] Ngarapihkeun surélék anu numpuk
- [ ] Nyiapkeun bahan presentasi dina sajam
- [ ] Nyarita di hareupeun jalma: latihan tanpa ribet
- [ ] Nginpokeun hasil pagawéan ka atasan sacara ringkas
- [ ] Ngawasaan alat anu tos aya sateuacan néangan anu énggal
- [ ] Nyieun ringkesan bacaan anu panjang

## Asisten AI (téknis, aman dibahas)

- [ ] Naon anu dimaksud "agén AI" jeung bédana jeung chatbot
- [ ] Naha asisten AI peryogi sababaraha modél (LLM) anu béda
- [ ] Peran MCP: nyambungkeun asisten jeung aplikasi pagawéan
- [ ] Narékahan pagawéan rutin nganggo otomasi kajadwalan
- [ ] Naha asisten leuwih saé dijalankeun di server sorangan
- [ ] Kumaha carana mariksa hasil pagawéan asisten
- [ ] Nyerat paréntah anu jelas (jeung anu sok gagal)
- [ ] Ngalatih asisten ku conto, sanés ku paréntah panjang
- [ ] Kanal komunikasi: WhatsApp, Telegram, surélék — iraha maké nu mana
- [ ] Ngukur manfaat asisten: naon anu kudu dihitung

## Komunikasi & nulis

- [ ] Nyerat pangumuman anu kaharti ku sakur jalma
- [ ] Nyusun surat resmi (jeung kasalahan anu sok diulang)
- [ ] Ngarobih catetan pribadi jadi tulisan anu kenging dibaca batur
- [ ] Nyieun ringkesan rapat anu aya kaputusanana
- [ ] Nyusun bahan pelatihan dina basa sapopoé
- [ ] Nyiapkeun laporan pikeun donatur atanapi mitra

## Cadangan (ide tambahan)

- [ ] Nyieun pituduh gancang (cheat sheet) pikeun alat anu sering dipaké
- [ ] Ngatur gambar jeung dokumén hasil kagiatan
- [ ] Nyusun rencana tilu bulan pikeun kagiatan organisasi
- [ ] Ngajarkeun batur maké alat anyar tanpa nyieun bosen
- [ ] Nyieun daptar pariksa (checklist) sateuacan kagiatan gedé
- [ ] Nyiapkeun panggantian upami pangurus teu aya
- [ ] Nyatet kaputusan rapat supaya teu dibahas deui
